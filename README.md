# Oficina Mecânica - Banco de Dados

Projeto desenvolvido na Atividade 7 da disciplina de Banco de Dados do curso Técnico em Desenvolvimento de Sistemas do SENAI.

## Sobre o projeto

O projeto consiste na modelagem e implementação de um banco de dados para a oficina mecânica Autotechnology Express.

O banco permite armazenar informações sobre:

- Clientes
- Veículos
- Mecânicos
- Ordens de serviço

## Banco de Dados

Nome do banco:

`oficina_mecanica_db`

## Tabelas

### Cliente
Armazena os dados dos clientes da oficina.

### Veiculo
Armazena os veículos cadastrados e relaciona cada veículo ao seu proprietário.

### Mecanico
Armazena os dados dos mecânicos da oficina.

### Ordem_Servico
Armazena as ordens de serviço, relacionando um veículo a um mecânico responsável.

## Funcionalidades utilizadas

Durante a atividade foram utilizados comandos SQL para:

- Criar o banco de dados
- Criar tabelas
- Definir chaves primárias e estrangeiras
- Utilizar restrições NOT NULL e UNIQUE
- Inserir registros
- Consultar registros
- Atualizar registros
- Excluir registros

## DER

Também foi desenvolvido um Diagrama de Entidade-Relacionamento (DER) para representar as tabelas e seus relacionamentos.

## Tecnologias utilizadas

- SQL Server
- SQL Server Management Studio (SSMS)
